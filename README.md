# 인터파크 티켓팅 매크로 (Interpark Ticket Macro) v2.0

이 프로젝트는 Python과 Selenium(`undetected-chromedriver`)을 활용하여 인터파크(NOL) 티켓 예매를 자동화하는 강력한 매크로입니다. 스포츠(프로야구, 축구, e스포츠 등) 티켓의 '취소표 잡기(새로고침 반복)' 및 '자동 좌석 선택'에 특화되어 설계되었습니다.

> [!WARNING]
> 본 프로젝트는 **학습 및 연구 목적**으로 작성되었습니다. 본 매크로를 무리하게 악용하여 발생하는 계정 정지, IP 차단, 혹은 예매 취소 등의 불이익에 대한 책임은 전적으로 사용자에게 있습니다.

## 🚀 주요 기능

- **강력한 봇 탐지 우회**: `undetected-chromedriver`를 사용하여 인터파크의 자동화 봇 차단 로직을 우회합니다.
- **자동 캡차(보안문자) 인식 및 통과**: `easyocr`과 OpenCV 이미지 전처리를 통해 알파벳 대문자 6자리 캡차를 자동으로 인식하고 통과합니다 (숫자 오인식 자동 교정 로직 포함).
- **스마트 구역/좌석 탐색**:
  - `consecutive_count`: 원하는 연석(연속 좌석) 개수 설정 및 부족한 구역 자동 스킵
  - `preferred_zones`: 선호하는 구역명(예: 테이블석, 응원석 등)을 포함하여 우선순위 지정 가능
  - `min_number` & `max_number`: 통로석이나 중앙석 등 특정 좌석 번호 대역을 지정하여 최우선으로 탐색 가능
  - 휠체어석 및 잔여석이 부족한 구역(0석 등) 자동 스킵
- **초고속 탐색 (딜레이 최소화)**: 좌석과 예매 버튼을 스캔할 때 Selenium의 Implicit Wait를 0으로 동적 조절하여 불필요한 딜레이를 완벽히 제거했습니다.
- **예외 상황 완벽 복구**: 팝업 차단, '이미 선점된 좌석입니다', '좌석 등급을 선택하세요' 등의 예기치 못한 Alert 창이 떠도 스크립트가 죽지 않고 안전하게 닫은 후 탐색을 재개합니다.
- **알림 및 안전 종료**:
  - 예매 성공 시 시스템 푸시 알림 및 비프음(경고음)으로 사용자에게 즉각 알림
  - 스크립트 종료 및 오류 발생 시에도 브라우저 창을 닫지 않고 유지(무한 대기 모드)하여 수동 결제 및 즉각 대응 지원
  - 지정한 횟수(`max_retry_rounds`) 도달 시 자동 종료되지 않고 터미널에서 연장 여부 묻기 적용

## 🛠️ 설치 및 실행

### 1. 요구 사항 (Requirements)
- Python 3.10 이상 권장
- `uv` (초고속 파이썬 패키지 매니저)

### 2. 패키지 설치 및 실행
이 프로젝트는 `uv`를 사용하도록 설정되어 있습니다. 터미널에서 아래 명령어로 의존성을 자동 설치하고 매크로를 실행할 수 있습니다.

```bash
# 기본 실행 방식 (예: 6월 13일 경기)
uv run python src/main.py --date 06.13
```

## ⚙️ 설정 가이드 (`config/settings.json`)

`config/settings.json` 파일을 수정하여 매크로의 동작을 세밀하게 제어할 수 있습니다.

- `seat_preference`:
  - `preferred_zones`: 우선 탐색할 구역 이름 배열 (위쪽에 적을수록 우선순위가 높습니다)
  - `consecutive_count`: 연석 필요 매수 (예: 2장 연석이면 `2`, 상관없으면 `1`)
  - `min_number` / `max_number`: 선호 좌석 번호 범위 (예: 한 열에서 6~17번 사이의 중앙석을 먼저 찾음)
- `max_retry_rounds`: 취소표를 찾기 위해 새로고침할 최대 횟수 (도달 시 프롬프트로 연장 여부 질문)
- `max_captcha_attempts`: 캡차 틀렸을 시 최대 재시도 횟수
