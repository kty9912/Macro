# 인터파크/NOL(야놀자) 티켓팅 매크로 v2.1

이 프로젝트는 Python과 Selenium(`undetected-chromedriver`)을 활용하여 인터파크(NOL) 티켓 예매를 자동화하는 매크로입니다.  
**정시 오픈 예매 모드**와 **취소표 잠복 모드**가 완벽히 분리되어 있어 상황에 맞추어 사용할 수 있습니다.

> [!WARNING]
> 본 프로젝트는 **학습 및 연구 목적**으로 작성되었습니다. 본 매크로를 악용하여 발생하는 계정 정지, IP 차단, 혹은 예매 취소 등의 불이익에 대한 책임은 전적으로 사용자에게 있습니다.

---

## 🚀 주요 기능 및 모드 분리

### 1. 🎯 정시 오픈 예매 모드 (`--mode open`)
* 티켓 오픈 시간(예: 11:00:00, 14:00:00)을 지정하면 정시까지 고정밀 카운트다운을 진행합니다.
* 정시 도달 시 자동으로 페이지를 새로고침하고 `예매하기` 버튼이 활성화되는 순간(밀리초 단위) 즉시 클릭합니다.
* 예매 팝업창 및 대기열 진입 ➔ 캡차 자동 통과 ➔ 선호 구역 및 연석 조건에 맞는 좌석을 즉시 선점합니다.

### 2. 🎣 취소표 잠복 모드 (`--mode cancel`)
* 이미 오픈되어 매진된 경기에서 잔여석/취소표를 노릴 때 사용합니다.
* 좌석 선택창에서 새로고침 루프를 반복하며 잔여석이 생기는 즉시 광속으로 낚아챕니다.
* 선점 충돌("이미 선택된 좌석입니다") 발생 시 0.05초 만에 Alert 창을 닫고 다음 좌석을 탐색합니다.

### 3. 🔐 유연한 로그인 지원
* 야놀자/인터파크 통합 인증 쿠키 및 화면 감지를 통해 자동 로그인을 감지합니다.
* 자동 감지가 안 되더라도 콘솔에서 **`[Enter]` 키만 누르면 즉시 수동 진행**이 가능합니다.

## 🛠️ 실행 방법

기존에 설치된 환경(`.venv`)으로 바로 실행할 수 있습니다.

```bash
# 1. 설정 검증 (브라우저 없이 빠른 점검)
python src/main.py --dry-run

# 2. [정시 오픈 모드] 오픈 시간 지정 (예: 14:00:00 오픈)
python src/main.py --mode open --date 10.07 --open-time 14:00:00

# 3. [정시 오픈 모드] 오픈 시간 없이 바로 오픈 탐색 진입
python src/main.py --mode open --date 10.07

# 4. [취소표 잠복 모드] 취소표/잔여석 반복 탐색
python src/main.py --mode cancel --date 10.07

# 5. 팀 변경 실행 (예: 두산, 키움, 수원삼성 등)
python src/main.py --mode open --team 두산 --date 10.07
```

## ⚙️ 설정 가이드 (`config/settings.json`)

* `team.name`: 응원 구단 (키움, 두산, 수원삼성, LCK 등)
* `seat_preference`:
  * `preferred_zones`: 우선 탐색할 구역 목록 (예: 테이블석, 다크버건디석 등)
  * `consecutive_count`: 연석 매수 (예: 3연석이면 `3`)
  * `min_number` / `max_number`: 선호 좌석 번호 대역 (통로석/중앙석 범위)
* `max_retry_rounds`: 취소표 잠복 최대 새로고침 횟수 (기본 500회)
